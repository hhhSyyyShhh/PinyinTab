Type Pinyin, press Tab, insert the real Chinese path.

Usage:
  ptab <command>
  ptab help [advanced] [en|zh]

Shell commands (require the Bash/Zsh integration to be loaded):
  on                Enable completion in the current shell
  off               Disable it and restore previous completers; not uninstall
  status            Show whether completion is enabled in this shell

Commands:
  doctor            Show version, platform and architecture
                    The shell integration also reports shell and ON/OFF state
  version           Show the program version
  update            Update an installed release; verification failures keep it intact
  help              Show this page (English); use "ptab help zh" for Chinese

Options:
  -h, --help        Show help
  -V, --version     Show the program version

Examples:
  ptab on
  cd ceshimulu<Tab>
  python3 ceshi.py<Tab>
  ./ceshi<Tab>
  ptab off
  ptab update

Notes:
  <Tab> means press the Tab key; do not type the literal characters.
  Completion inserts a real path. It never renames files or runs candidates.
  ./ completion requires an executable file (or a directory to navigate).
  on/off affect this shell only. Normal installs start OFF in new shells.
  The optional startup flag and Oh My Zsh plugin can explicitly opt in.

Language selection (Bash 5 / Zsh, while completion is ON):
  Tab               Prefer non-Chinese names; use Chinese if none match
  Ctrl+X, then c    Complete Chinese names, before or immediately after Tab
  Ctrl+X, then e    Complete non-Chinese names, or switch back after c
  On Mac use Control, not Command. These are sequential key presses.
  Exact real names stay unchanged; a space starts the next argument.
  At a complete name, Ctrl+X then e/c selects existing whole-name counterparts.
  Example: 测试.py -> Ctrl+X, then e -> cs.py (when it exists uniquely).
  Multiple candidates still require refinement; the plugin does not guess.
  Updates preserve startup settings. Reopen the terminal after updating.
  Manually downloaded archives are not automatically deleted.

Advanced interfaces:
  ptab help advanced       Alias queries and the shell completion protocol
  ptab help advanced zh    The same reference in Chinese
